# AGENTS.md: read this before you make anything for this brand

You are making content for **<Brand>**: posts, articles, images, video, decks, web or code. Person or AI agent, these rules apply.

## Load order

1. `brand.json`: the whole genome in one file. Read it fully.
2. The folder for your job: writing → `02-voice/` + `07-content-kits/`; images and video → `04-identity/` + `05-characters/` + `08-prompts/`; UI and code → `06-design-system/`.
3. `03-facts/facts.md` before you write any number.

## Rules

1. **The customer is the hero.** The brand is the guide.
2. **The villain is a problem or a model, never a person, nationality, culture or group.**
3. **Only `ready` facts** (or `framed`, exactly as described). Missing a number? Write `[FACT NEEDED]`. Never invent one.
4. **Always positive.** Faces smile or look curious, amused or confident.
5. **Real people only with consent.** Never fake testimonials or AI "customers".
6. **Everything ships through a pull request** with the brief filled in.
